Automata and Parsing Tools

Interactive visualisations for teaching regular languages, bottom-up parsing, and top-down parsing. Enter a regular expression or grammar in BNF, step through automaton and table construction, then simulate string recognition or parsing a string with full parse tree growth.

Regular Expressions Thompson's construction  —  RE → NFA → DFA, step-by-step, string simulation LR Parser LR(0) · SLR(1) · LALR(1) · LR(1)  —  characteristic automaton, ACTION/GOTO tables, string simulation, parse tree LL(1) Parser Predictive parsing  —  FIRST/FOLLOW sets, predictive table, derivation steps, string simulation, parse tree Grammar Transformations Cleanup · ε-elimination · unit elimination · Chomsky Normal Form · left-recursion elimination

Made by August Ernstsson in large part using Claude Code.

These tools are experimental and not guaranteed to be correct representations of course theory material.
