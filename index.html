Automata and Parsing Tools

Interactive visualisations for teaching formal language theory and parsing. Step through automaton and table construction, simulate string recognition, and grow parse trees.

Regular languages
Regular Expressions Thompson's construction  —  RE → NFA → DFA, step-by-step, string simulation NFA Simulator ε-NFA  —  editable transition table, NFA graph, nondeterministic simulation tree
Context-free languages
Grammar Transformations Cleanup · ε-elimination · unit elimination · Chomsky Normal Form · left-recursion elimination Grammar Derivations Manual derivations  —  CFG · CSG · Type 0  —  select a range, choose a rule, build the sentential form step by step PDA Simulator Nondeterministic PDA · ε-PDA  —  transition rule list, automaton graph, configuration-set simulation LL(1) Parser Predictive parsing  —  FIRST/FOLLOW sets, predictive table, derivation steps, string simulation, parse tree LR Parser LR(0) · SLR(1) · LALR(1) · LR(1)  —  characteristic automaton, ACTION/GOTO tables, string simulation, parse tree
Recursively enumerable languages
Turing Machine Deterministic TM  —  editable transition table, tape simulation, step-by-step execution

Made by August Ernstsson in large part using Claude Code.

These tools are experimental and not guaranteed to be correct representations of course theory material.
