This is a suite of browser-based teaching tools for parsing of context-free languages and underlying formal langauges and automata theory.
The user can input their own BNF grammar and strings to parse.

Two main tools exist:
— LR parsing tools. Build parsing tables interactively with automaton graph and parsing table views. Simulate parsing interactively with bottom-up parse tree generation.
— LL parsing tools. Predictive parsing. Build the LL table. Simulate parsing interactively with top-down parse tree generation.

Uses the D3 graphing library for rich node rendering.
